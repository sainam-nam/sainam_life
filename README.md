# sainam_life
โปรเจคทดลองสำหรับจัดการ tasks, bugs และ notes เพื่อฝึกพื้นฐานการพัฒนาและ testing workflow

## จุดประสงค์ของโปรเจค

โปรเจคนี้ไม่ได้ถูกออกแบบมาเพื่อใช้งานจริงใน production แต่มีเป้าหมายเพื่อ:
- ทดลองแนวคิดการออกแบบระบบ
- ฝึกการเขียน frontend และ backend ร่วมกัน
- ใช้เป็นพื้นที่สำหรับลอง implement feature ใหม่ ๆ
- ฝึกการทำ testing แบบพื้นฐาน

## Features (CRUD)
- จัดการ Tasks 
- บันทึก Bugs ที่พบระหว่างพัฒนาโปรเจคต่างๆ
- จด Notes ต่างๆ

## Tech Stack
- Frontend: React
- Styling: Tailwind CSS
- Backend: Node.js / Express / MySQL

📌 หมายเหตุ
โปรเจคนี้เป็นเพียงโปรเจคสำหรับการเรียนรู้และทดลองเท่านั้น อาจมีโค้ดที่ยังไม่สมบูรณ์ หรือไม่ได้ optimize สำหรับการใช้งานจริง

## Testing (Playwright)
โปรเจคนี้มีการทดลองใช้ automated testing เบื้องต้น โดยใช้ Playwright เพื่อทดสอบการทำงานของระบบในมุมมองของผู้ใช้งานจริง (End-to-End Testing)
